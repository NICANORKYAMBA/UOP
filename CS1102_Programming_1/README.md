# CS 1102: Programming 1 — Java

**University of the People**
**Textbook**: Eck, D. J. (2022). *Introduction to programming using Java* (Version 9, JavaFX ed.). CC 4.0.

---

## Course Structure

| Unit | Topic | Deliverables |
|------|-------|-------------|
| 1 | Introduction to Java Programming | Discussion, Programming Assignment, Self-Quiz |
| 2 | Control Structures | Discussion, Programming Assignment, Self-Quiz |
| 3 | Static Methods and Member Variables | Peer Feedback, Programming Assignment, Self-Quiz, **Graded Quiz** |
| 4 | Arrays and ArrayLists | Discussion, Programming Assignment, Self-Quiz |
| 5 | Objects and Classes | Discussion, Programming Assignment, Self-Quiz |
| 6 | OOP Paradigms | Discussion, Programming Assignment, Self-Quiz, **Graded Quiz** |
| 7 | GUI with Event Handling | Discussion, Programming Assignment, Self-Quiz |
| 8 | Collection API and Java 8 Features | Discussion, Programming Assignment, Self-Quiz |
| 9 | Final Exam | Review Quiz, Final Exam |

## Grading Weights

| Component | Weight |
|-----------|--------|
| Discussion Forum Units 1–4 | 15% |
| Discussion Forum Units 5–8 | 10% |

| Graded Quizzes (2) | 20% |
| Final Exam | 15% |

## Key Notes

- Language: **Java** (latest JDK from Oracle)
- IDE: **Eclipse** (latest version)
- Textbook: Eck (2022) — free PDF, CC 4.0
- APA 7th edition for all citations
- Programming assignments graded by instructor with rubric
- Graded Quizzes in Units 3 and 6
- Final Exam: Week 9, one attempt, no materials allowed
