## Course Learning Outcomes

| CLO | Description |
|-----|-------------|
| CLO1 | Summarize basic algebra/trig concepts using textbooks, graphs, calculators |
| CLO2 | Solve algebraic and trigonometric problems |
| CLO3 | Interpret algebraic/trig concepts using graphs |
| CLO4 | Apply algebraic/trig concepts to mathematical models |
