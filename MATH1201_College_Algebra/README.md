# MATH 1201: College Algebra

**University of the People**
**Term**: AY2027-T1 (Ends January 31, 2027)
**Credits**: 3
**Prerequisites**: None

---

## Course Description

This course provides a solid grounding in algebra, trigonometry, and analytic geometry
in preparation for further mathematical studies. It includes an extensive study of
linear, quadratic, and rational functions, an introduction to exponential and
logarithmic functions and circles, and systems of linear equations.

---

## Course Learning Outcomes (CLOs)

- **CLO1**: Summarize the basic concepts of algebra and trigonometry using various resources (textbooks, graphs, scientific calculators).
- **CLO2**: Solve algebraic and trigonometric problems.
- **CLO3**: Interpret algebraic and trigonometric concepts using graphs.
- **CLO4**: Apply algebraic and trigonometric concepts to mathematical models.

## ⚠️ Proctored Final Exam (Rosalyn)

The Unit 9 Final Exam is **proctored using Rosalyn**, a secure online proctoring system.

**Permitted materials during the exam**: paper, pencil, calculator.

**Before the exam window opens:**
- Review the Rosalyn Student Guide and Proctored Final Exams Guide (in the LRC).
- Use a **Windows or macOS computer** (mobile devices are NOT supported).
- Install the **Rosalyn desktop application** in advance.
- Confirm webcam, microphone, and internet are working.

**When the window opens (Thu–Sun of Week 9):**
- Enter Rosalyn early to run system checks and verify identity.
- Launch Rosalyn from Brightspace, grant camera/mic/screen permissions.
- Close all other browsers and applications before starting.

**During the exam:**
- One attempt only. The exam **cannot be paused**.
- Leaving or closing the session **terminates your only attempt**.
- Work independently; the session is monitored and recorded.
