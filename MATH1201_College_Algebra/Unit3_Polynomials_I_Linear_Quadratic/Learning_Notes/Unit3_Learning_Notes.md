# Unit 3 Learning Notes — Linear and Quadratic Functions

Course: MATH 1201 College Algebra
Readings: Abramson (2023) Ch. 4.1 & 5.1; Stitz & Zeager (2013) §2.1; Yoshiwara (2020) §1.5

---

## 1. Linear functions

- **Form:** f(x) = mx + b, where m = slope and b = y-intercept.
- **Slope:** m = (y₂ − y₁)/(x₂ − x₁) = rise/run = the constant rate of change.
- **Point-slope form:** y − y₁ = m(x − x₁) — best when you know a point and the slope.
- **Slope-intercept form:** y = mx + b — best for graphing and reading the intercept.
- **Intercepts:** y-intercept at x = 0 (gives b); x-intercept at y = 0 (solve mx + b = 0).
- **Parallel lines:** equal slopes (m₁ = m₂).
- **Perpendicular lines:** slopes are negative reciprocals (m₁·m₂ = −1, so m₂ = −1/m₁).
- **Average rate of change** of a linear function is constant and equals the slope.

## 2. Quadratic functions

- **General form:** f(x) = ax² + bx + c (a ≠ 0). Graph is a **parabola**.
- **Opening:** opens **up** if a > 0 (has a minimum); opens **down** if a < 0 (has a maximum).
- **Vertex:** x = −b/(2a); the y-value f(−b/(2a)) is the max or min.
- **Axis of symmetry:** the vertical line x = −b/(2a) through the vertex.
- **Vertex form:** f(x) = a(x − h)² + k, with vertex (h, k).
- **x-intercepts (roots):** solve ax² + bx + c = 0 (factor, complete the square, or quadratic
  formula x = (−b ± √(b² − 4ac))/(2a)).
- **y-intercept:** f(0) = c.

## 3. Reading a parabola graph

- Increasing/decreasing: for a downward parabola, the function increases left of the vertex
  and decreases right of it (reverse for upward). In an applied problem, restrict to the
  physically meaningful interval.
- The axis of symmetry pairs up points of equal height on either side of the vertex.

## 4. Applying to models (this unit's tasks)

- **Projectile / falling object:** h(t) = −0.5t² + v₀t + h₀ style models. Vertex = highest
  point; t-intercept = when it hits the ground/water; axis of symmetry = time of the peak.
- **Road/line between two points:** compute slope from the two points, then write the line;
  parallel = same slope, perpendicular = negative reciprocal.
- **Cost model:** C = fixed + rate × quantity is linear; the rate is the slope and the average
  rate of change; the fixed charge is the y-intercept.

## 5. Self-Quiz reminders

- x-intercepts of x² − k are ±√k.
- Vertex form (x − h)² + k expands to x² − 2hx + (h² + k); a vertex (1, −2) gives x² − 2x − 1.
- Line through two points: find slope first, then point-slope.
- A projectile taking T seconds to land (symmetric arc) peaks at t = T/2.
