## Task 1: Quadratic Function — Bungee Jumper

Model with v₀ = 0, h₀ = 210: **h(t) = −0.5t² + 210**.

### Part 1(i): Mathematical Understanding

1. **Domain and range.** Physically t runs from 0 to when h = 0. Solving 0.5t² = 210 →
   t² = 420 → t = √420 ≈ 20.49 s. **Domain [0, 20.49] s; range [0, 210] m.** Domain = duration
   of the fall; range = heights passed from bridge to river.
2. **Vertex.** t = −b/(2a) = 0/(2·−0.5) = 0; h(0) = 210. **Vertex (0, 210)** — the start of
   the jump at maximum height (parabola opens down since a < 0).
3. **Maximum height.** At the vertex: **t = 0 s, h = 210 m.** With v₀ = 0 the jumper is
   released from rest at the top.
4. **Height = 11 m.** −0.5t² + 210 = 11 → 0.5t² = 199 → t² = 398 → **t = √398 ≈ 19.95 s.**
5. **Height after 20 s.** h(20) = −0.5(400) + 210 = −200 + 210 = **10 m** (near the water).
6. **Touches river (h = 0).** t² = 420 → **t = √420 ≈ 20.49 s.**

### Part 1(ii): Graphical Understanding

7. **Graph.** Downward parabola, vertex (0, 210), t-intercept ≈ (20.49, 0). See GeoGebra
   graph (placeholder in docx).
8. **Increasing/decreasing.** On the physical branch (0, 20.49) the height only **decreases**;
   it is never increasing during the jump.
9. **Axis of symmetry.** t = −b/(2a) = **0** (the line t = 0). Because v₀ = 0, the launch
   coincides with the parabola's turning point.
10. **Intercepts.** h-intercept (0, 210) = initial bridge height; t-intercept (20.49, 0) =
    time the jumper reaches the river.

## Task 2: Linear Function — Road Project (A(5,7), B(6,5))

1. **Equation of the road.** m = (5 − 7)/(6 − 5) = −2. Point-slope through A: y − 7 = −2(x − 5)
   → **y = −2x + 17.**
2. **Slope.** **m = −2** — road drops 2 units per 1 unit of horizontal travel.
3. **Elevation change A→B.** Δy = −2 over Δx = 1 → descends 2 units per unit run.
4. **Parallel & perpendicular.** Parallel slope = −2 (e.g., y = −2x). Perpendicular slope =
   1/2 (e.g., through A: **y = ½x + 4.5**).
5. **Graph.** Road with A, B, plus parallel and perpendicular routes (GeoGebra placeholder).
6. **Intercepts.** y-intercept (0, 17); x-intercept (8.5, 0) — road access/landmarks.
7. **How many parallel/perpendicular roads?** **Infinitely many** of each (a slope plus any
   of infinitely many points fixes a line).

## Task 3: Linear Function II — Electricity Pricing

1. **Linear function.** Let u = units consumed, C(u) = total monthly cost ($).
   **C(u) = 50 + 0.78u** (50 = fixed charge, 0.78 = cost per unit).
2. **Average rate of change.** For a line it equals the slope. C(100) = 128, C(200) = 206;
   (206 − 128)/(200 − 100) = 78/100 = **$0.78 per unit.** Each extra unit adds exactly $0.78 to
   the bill, so cost is predictable and reducing one unit saves $0.78.
