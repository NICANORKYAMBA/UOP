## PART B — GeoGebra graphs you will create (for the final document)

Once I have the functions, you'll make these graphs in GeoGebra
(https://www.geogebra.org/calculator) and paste them into the Word document at the marked
spots. Here is the general how-to; I'll give you the exact functions to type after I see the
screenshots.

### Task 3 graph — the base function and its 4 transformations (all 5 on one screen)
1. Open GeoGebra. In the Input bar, type the **base function**, e.g. `f(x) = x^2`, press Enter.
2. On new lines, type each of the **four transformations** exactly as the assignment gives
   them, e.g. `g(x) = f(x) + 3`, `h(x) = f(x - 2)`, `p(x) = -f(x)`, `q(x) = 2 f(x)`.
   - GeoGebra lets you reference f(x), so transformations can be written in terms of f.
3. All five curves appear together, each a different color. GeoGebra auto-labels them.
4. Adjust the view (scroll/zoom) so all five are clearly visible.
5. Screenshot: GeoGebra menu (three lines) → **Download / Export Image → PNG**, or Flameshot
   the graph area. This one image covers Task 3(i) — "draw all 5 graphs."

### Task 2 graph (only if the task asks for one — many inverse tasks don't require a graph)
If you want to show the function and its inverse:
1. Type the original `T(x) = <the function>` (use x in place of C for plotting).
2. Type the inverse once we compute it, e.g. `C(x) = (x - 15)/2`.
3. Optionally type `y = x` to show the inverse is a mirror reflection across that line.
