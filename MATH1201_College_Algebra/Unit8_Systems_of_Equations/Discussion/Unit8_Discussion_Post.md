A system of linear equations is classified by how many solutions it has, which in two variables
is how many points its lines share (Abramson, 2021, Section 11.1).

**Consistent.** A consistent system has at least one solution: its lines meet somewhere.
Every consistent system is either independent or dependent.

**Independent (one solution).** The lines have different slopes and cross at exactly one point.

- x + y = 5 and x - y = 1. Adding the equations gives 2x = 6, so x = 3 and y = 2. The only
  solution is (3, 2).

**Dependent (infinitely many solutions).** Both equations describe the same line, so every point
on it is a solution.

- x + y = 5 and 2x + 2y = 10. The second equation is the first multiplied by 2. The solutions
  are all points (x, 5 - x), such as (0, 5) and (1, 4).

**Inconsistent (no solution).** The lines are parallel: they have the same slope but different
y-intercepts, so they never meet.

- x + y = 5 and x + y = 2. Subtracting gives 0 = 3, which is false, so there is no solution.

Elimination shows the type quickly (Mathispower4u, 2009): a single value for each variable means
independent, a true statement such as 0 = 0 means dependent, and a false statement such as
0 = 3 means inconsistent.
