# MATH 1280 Unit 1 Learning Notes: Sampling and Data

Reading: Illowsky et al. (2023), *Introductory Statistics 2e*, Sections 1.1 to 1.3. The final exam is proctored (Rosalyn) and allows a pen, pencil, calculator, and printed distribution tables.

## Key terms (Section 1.1)
| Term | Meaning | Café example |
|---|---|---|
| Statistics | Collecting, organizing, analyzing, interpreting data | The whole survey project |
| Probability | Mathematics of chance | P(next order is cappuccino) = 0.30 |
| Population | Every individual of interest | All café customers |
| Sample | The part we actually study | 100 surveyed customers |
| Parameter | Number describing the population | True % of all customers who like cappuccino |
| Statistic | Number describing the sample | 30% of the 100 surveyed |
| Variable | Characteristic measured | Favourite drink |
| Data | Actual values of the variable | "Cappuccino", "Tea" |

Memory trick: **P**arameter goes with **P**opulation, **S**tatistic goes with **S**ample.

## Sampling methods (Section 1.2)
| Method | How | Example |
|---|---|---|
| Simple random | Every member equally likely | Random numbers from the full customer list |
| Stratified | Split into strata, random sample from each | 60 morning + 40 evening customers |
| Cluster | Split into clusters, take all members of some random clusters | Survey everyone in 3 randomly chosen branches |
| Systematic | Random start, then every nth member | Every 10th receipt |
| Convenience (not random) | Whoever is easy to reach | Asking friends only, biased |

Stratified = some from **every** group. Cluster = **all** from **some** groups.
Sampling with replacement allows a member to be picked twice; without replacement does not.
Sampling bias: some members are less likely to be chosen, so conclusions can be wrong.

## Types of data
- **Qualitative (categorical):** colours, drink names.
- **Quantitative discrete:** counts (number of family members).
- **Quantitative continuous:** measurements (hours studied, weight).

## Levels of measurement (Section 1.3)
| Level | Order? | Equal gaps? | True zero? | Example |
|---|---|---|---|---|
| Nominal | No | No | No | Eye colour |
| Ordinal | Yes | No | No | Small, medium, large |
| Interval | Yes | Yes | No | Temperature in °C |
| Ratio | Yes | Yes | Yes | Number of family members, money |

## Frequency tables
- **Frequency (f):** how many times a value occurs.
- **Relative frequency:** f / n (sums to 1).
- **Cumulative relative frequency:** running total of relative frequencies (last one = 1).
- **Cumulative frequency:** running total of frequencies. Class frequency = this row's cumulative frequency minus the previous row's.
- Check interval rules: usually lower bound included, upper bound excluded.
