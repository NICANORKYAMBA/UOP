## 🎯 Key Concepts to Master

### 1. Analyzing Sources
- **Credibility Assessment**: Author credentials, publication venue, peer review
- **Relevance Evaluation**: Connection to research question, currency, scope
- **Bias Detection**: Author perspective, funding sources, methodology
- **Quality Indicators**: Research design, sample size, statistical significance

### 2. Paraphrasing Techniques
- **Read and Understand**: Fully comprehend the original text
- **Set Aside**: Don't look at the original while paraphrasing
- **Rewrite in Your Own Words**: Use different sentence structure and vocabulary
- **Check Against Original**: Ensure meaning is preserved
- **Cite Properly**: Always include in-text citation

### 3. Synthesizing Information
- **Compare and Contrast**: Identify similarities and differences
- **Identify Themes**: Group sources by common topics
- **Show Relationships**: Explain how sources support/contradict each other
- **Build Arguments**: Use multiple sources to support claims
- **Create New Insights**: Go beyond summarizing to analyze

### 4. Identifying Gaps
- **Types of Gaps**:
  - Knowledge gaps (unexplored topics)
  - Methodological gaps (new research methods needed)
  - Population gaps (understudied groups)
  - Practical gaps (theory vs. application)
  - Empirical gaps (lack of data)
- **Gap Statement Formula**: "While X has been studied, Y remains unexplored..."

## 💡 Study Tips

### For Source Analysis
1. Use the CRAAP test (Currency, Relevance, Authority, Accuracy, Purpose)
2. Create a source evaluation matrix
3. Take notes on strengths and limitations of each source
4. Identify how each source relates to your research question

### For Paraphrasing
1. Read the passage multiple times
2. Explain it to yourself in simple terms
3. Write without looking at the original
4. Compare to ensure you haven't copied phrases
5. Always cite, even when paraphrasing

### For Synthesis
1. Create a concept map showing connections between sources
2. Use transition words (similarly, in contrast, furthermore)
3. Don't just list sources—show relationships
4. Build toward your own argument

### For Gap Identification
1. Look for phrases like "future research should..." in sources
2. Notice what questions remain unanswered
3. Consider new populations, contexts, or methods
4. Think about practical applications not yet explored
