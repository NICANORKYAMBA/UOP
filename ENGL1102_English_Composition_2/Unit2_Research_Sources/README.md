## 📚 Key Concepts

### SMART Goals
- **S**pecific
- **M**easurable
- **A**chievable
- **R**elevant
- **T**ime-bound

### Rhetorical Modes
1. **Argumentative**: Present a claim with evidence and counterarguments
2. **Persuasive**: Convince readers to adopt a viewpoint or take action
3. **Expository**: Explain or inform about a topic objectively
4. **Narrative**: Tell a story with characters, plot, and setting
5. **Descriptive**: Paint a vivid picture using sensory details

### Credible Sources Criteria
- Peer-reviewed journals
- Reputable authors with credentials
- Recent publication dates
- Data reliability and methodology
- Unbiased presentation
- Proper citations and references

### Five-Paragraph Essay Structure
1. **Introduction**: Hook, background, thesis statement
2. **Body Paragraph 1**: Topic sentence, supporting evidence, analysis
3. **Body Paragraph 2**: Topic sentence, supporting evidence, analysis
4. **Body Paragraph 3**: Topic sentence, supporting evidence, analysis
5. **Conclusion**: Restate thesis, summarize main points, closing thought
