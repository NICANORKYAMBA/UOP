## 📚 KEY CONCEPTS TO MASTER

### 1. Core Components
- Data, Tables, Schema, Queries, Indexes, Relationships
- How they work together
- Examples in real systems

### 2. File Systems Problems
- Data redundancy
- Data inconsistency
- Difficulty in access
- Data isolation
- Integrity problems
- Atomicity issues
- Concurrent access anomalies
- Security problems

### 3. DBMS Advantages
- Data independence
- Reduced redundancy
- Data consistency
- Data integrity
- Improved security
- Concurrent access control
- Backup and recovery
- Data sharing
- Improved access
- Standardization

### 4. DBMS Disadvantages
- High initial cost
- Complexity
- Overhead costs
- Performance overhead
- Single point of failure
- Vendor lock-in
- Security vulnerabilities
- Specialized skills required

### 5. DBMS Classification
- **By Data Model:** Hierarchical, Network, Relational, Object-Oriented, NoSQL
- **By Users:** Single-user, Multi-user
- **By Location:** Centralized, Distributed, Cloud

### 6. Three-Schema Architecture
- **Physical Level:** How data is stored
- **Logical Level:** What data is stored
- **View Level:** How users see data

### 7. Data Independence
- **Physical:** Change storage without affecting logic
- **Logical:** Change schema without affecting applications
