# CS 2203 Self-Quiz Unit 1: Answers and Reasons

Ungraded, unlimited attempts. Check the feedback after submitting and update this file to the key.

| Q | Answer | Why |
|---|---|---|
| 1 | Developers primarily write code for applications, while DBAs manage and maintain the database system | Sharma et al. (2010, pp. 33-34): the DBA handles maintenance, performance, integrity and security; the application developer builds applications that access the database |
| 2 | To minimize data redundancy | Related tables share keys instead of repeating the same data (Watt & Eng, 2014, Chapter 3, control of data redundancy) |
| 3 | Managing and optimizing database connections (less certain) | None of the options matches the book exactly. The database architect designs the database solution, its standards, availability and backups (Sharma et al., 2010, pp. 32-33). This is the only option about the database system itself; network design, visualizations and heavy SQL belong to other roles |
| 4 | To organize and manage large volumes of data | The core purpose of a database (Sharma et al., 2010, p. 23) |
| 5 | RDBMS only store structured data, while others handle unstructured data (less certain) | RDBMS keep data in tables with a fixed schema. "Schema-less" describes NoSQL, and network and hierarchical DBMS do support relationships, so the other options are false |
