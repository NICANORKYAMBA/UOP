❓ QUICK REFERENCE

BOOLEAN OPERATORS:
⋅ = AND
+ = OR
′ = NOT

BOOLEAN LAWS USED:
- Distributive Law: X⋅Y + X⋅Z = X⋅(Y + Z)
- De Morgan's: (X⋅Y)′ = X′ + Y′
- Double Complement: X′′ = X

LOGIC GATES:
NOT: Inverts input
OR: Output = 1 if any input is 1
AND: Output = 1 only if all inputs are 1

SCENARIO VARIABLES:
I = ID Scanned (valid ID card)
L = Lab Available (lab not in use)
A = Admin Override (manual access allowed)
