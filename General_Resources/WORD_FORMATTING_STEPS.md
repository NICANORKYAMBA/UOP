MICROSOFT WORD FORMATTING GUIDE - STEP BY STEP
═══════════════════════════════════════════════════════════════════════════════

Follow these exact steps to format your assignment correctly in Microsoft Word.

═══════════════════════════════════════════════════════════════════════════════
STEP 1: OPEN AND PASTE CONTENT
═══════════════════════════════════════════════════════════════════════════════

1. Open the file: CS1111_Assignment_SUBMIT_THIS.txt
2. Select all content:
   - Windows: Press Ctrl + A
   - Mac: Press Cmd + A
3. Copy the content:
   - Windows: Press Ctrl + C
   - Mac: Press Cmd + C
4. Open Microsoft Word (blank document)
5. Paste the content:
   - Windows: Press Ctrl + V
   - Mac: Press Cmd + V

═══════════════════════════════════════════════════════════════════════════════
STEP 2: SET FONT TO TIMES NEW ROMAN, 12PT
═══════════════════════════════════════════════════════════════════════════════

1. Select all text:
   - Windows: Press Ctrl + A
   - Mac: Press Cmd + A

2. Change font:
   - Look at the top toolbar
   - Find the font dropdown (usually shows "Calibri" or current font)
   - Click the dropdown arrow
   - Scroll down and select "Times New Roman"

3. Change font size:
   - Look at the top toolbar next to font name
   - Find the size dropdown (usually shows "11" or current size)
   - Click the dropdown arrow
   - Select "12"

SHORTCUT METHOD:
- Select all (Ctrl+A / Cmd+A)
- Press Ctrl+D (Windows) or Cmd+D (Mac) to open Font dialog
- Select "Times New Roman" from font list
- Select "12" from size list
- Click OK

═══════════════════════════════════════════════════════════════════════════════
STEP 3: SET DOUBLE SPACING
═══════════════════════════════════════════════════════════════════════════════

METHOD 1 - Using Toolbar:
1. Keep all text selected (Ctrl+A / Cmd+A)
2. Look at the "Home" tab (top of screen)
3. Find the "Paragraph" section
4. Click the line spacing icon (looks like lines with arrows)
5. Select "2.0" from the dropdown

METHOD 2 - Using Paragraph Dialog:
1. Keep all text selected (Ctrl+A / Cmd+A)
2. Right-click on selected text
3. Choose "Paragraph" from menu
4. In the "Indents and Spacing" tab:
   - Find "Line spacing" dropdown
   - Select "Double"
   - Click OK

METHOD 3 - Keyboard Shortcut:
1. Select all text (Ctrl+A / Cmd+A)
2. Press Ctrl+2 (Windows) or Cmd+2 (Mac)

═══════════════════════════════════════════════════════════════════════════════
STEP 4: SET ALIGNMENT TO LEFT
═══════════════════════════════════════════════════════════════════════════════

1. Keep all text selected (Ctrl+A / Cmd+A)
2. Look at the "Home" tab
3. Find the "Paragraph" section
4. Click the "Align Left" button (lines aligned to left)

SHORTCUT:
- Windows: Press Ctrl+L
- Mac: Press Cmd+L

═══════════════════════════════════════════════════════════════════════════════
STEP 5: FIX REFERENCE PAGE SPACING
═══════════════════════════════════════════════════════════════════════════════

The reference should start on a new line after "Word Count: 746"

1. Place cursor at the end of "Word Count: 746"
2. Press Enter twice to create space
3. The "References" heading should now have space above it

═══════════════════════════════════════════════════════════════════════════════
STEP 6: CHECK WORD COUNT
═══════════════════════════════════════════════════════════════════════════════

1. Select ONLY the body text (from "Introduction" to "Conclusion" paragraph)
   - Do NOT include: Title, "Word Count: 746", or References section

2. Check word count:
   - Look at bottom left of Word window
   - Should show word count (around 746 words)
   - OR go to "Review" tab → Click "Word Count"

3. Verify it's between 500-750 words

NOTE: The assignment instructions say word count should NOT include:
- Title
- Reference list
So your body text should be 746 words ✓

═══════════════════════════════════════════════════════════════════════════════
STEP 7: ADD PAGE NUMBERS (OPTIONAL - CHECK WITH INSTRUCTOR)
═══════════════════════════════════════════════════════════════════════════════

If your instructor requires page numbers:

1. Go to "Insert" tab
2. Click "Page Number"
3. Choose "Bottom of Page" or "Top of Page"
4. Select a simple style (usually "Plain Number 3" - centered)

═══════════════════════════════════════════════════════════════════════════════
STEP 8: SAVE YOUR DOCUMENT
═══════════════════════════════════════════════════════════════════════════════

1. Click "File" → "Save As"
2. Choose location (Desktop or Documents folder)
3. Name your file:
   - Format: YourLastName_FirstName_CS1111_Unit1_Assignment.docx
   - Example: Kyamba_Nicanor_CS1111_Unit1_Assignment.docx
4. Make sure "Save as type" is "Word Document (*.docx)"
5. Click "Save"

BACKUP COPY:
- Save another copy to cloud storage (Google Drive, OneDrive, Dropbox)
- Or email yourself a copy

TROUBLESHOOTING COMMON ISSUES
═══════════════════════════════════════════════════════════════════════════════

ISSUE: Text looks too cramped
FIX: Make sure you selected "Double" spacing (2.0), not 1.5

ISSUE: Font looks different in some parts
FIX: Select all text again (Ctrl+A) and reapply Times New Roman

ISSUE: Word count is different
FIX: Make sure you're only counting body text, not title or references

ISSUE: Can't find Times New Roman font
FIX: It should be installed by default. Try typing "Times" in font box

ISSUE: File won't upload
FIX: 
- Check file size (should be small, under 1MB)
- Make sure it's saved as .docx, not .doc
- Try different browser (Chrome, Firefox, Edge)
- Check internet connection

ISSUE: Spacing looks weird after pasting
FIX: 
- Select all (Ctrl+A)
- Go to Home tab → Paragraph section
- Click small arrow in bottom right corner
- Under "Spacing", set "Before" and "After" to 0 pt
- Set "Line spacing" to "Double"
- Click OK
