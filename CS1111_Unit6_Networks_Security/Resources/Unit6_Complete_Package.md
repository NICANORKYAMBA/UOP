💡 KEY CONCEPTS TO REMEMBER
═══════════════════════════════════════════════════════════════════════════════

NETWORKS:
⭐ LAN = best for small business
⭐ Star topology = easy management, fault isolation
⭐ Full-duplex = modern standard, simultaneous communication
⭐ Switch = Layer 2, intelligent forwarding
⭐ Router = Layer 3, connects networks, gateway to Internet

INTERNET:
⭐ ISP = provides internet access
⭐ DNS = translates domain names → IP addresses
⭐ IPv4 = 32-bit, running out
⭐ IPv6 = 128-bit, future
⭐ Browser = renders web pages
⭐ Search engine = crawl, index, rank

SECURITY:
⭐ CIA Triad = Confidentiality, Integrity, Availability
⭐ Virus = needs host, requires user action
⭐ Worm = self-replicating, spreads automatically
⭐ Trojan = disguised as legitimate
⭐ Firewall = network security barrier
⭐ Defense-in-depth = multiple security layers
