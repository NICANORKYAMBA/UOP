# CS1101 - Programming Fundamentals - Syllabus Summary

## Course Information
- **Course Code**: CS 1101
- **Course Title**: Programming Fundamentals
- **Credits**: 3
- **Prerequisites**: None
- **Programming Language**: Python 3
- **Duration**: 9 weeks (8 units + final exam)

---

## Course Description

This course covers the basics of computer programming and provides a foundation for further learning. No previous programming knowledge required. Uses Python programming language with focus on abstract concepts applicable to any programming language. Emphasis on thinking like a programmer.

---

## Required Textbook

**Title**: Think Python: How to Think Like a Computer Scientist  
**Author**: Allen Downey (2015)  
**Format**: Free PDF (Open Educational Resource)  
**Location**: Available in Resources folder

## Learning Objectives

By the end of this course, students will be able to:

1. **Implement code** using fundamental programming concepts, language constructs, and procedural programming approaches
2. **Develop programs** using Python to solve programming problems
3. **Independently research** programming languages and apply new features

Each unit follows this pattern:

### Tasks Per Unit
1. ✅ **Read Learning Guide** and Reading Assignment
2. ✅ **Participate in Discussion** (post + comment on peers)
3. ✅ **Complete Programming Assignment** (submit code)
4. ✅ **Take Self-Quiz** (practice assessment)

## Key Topics Breakdown

### Fundamentals (Units 1-2)
- Programming basics
- Variables and data types
- Expressions and statements

- Conditionals (if/else)
- Recursion
- Function return values
- Fruitful functions

### Data Structures (Units 5-7)

- Strings
- Lists
- Dictionaries
- Tuples

- Writing files
- File handling

## Success Tips

1. **Install Python early** (Week 1)
2. **Practice coding daily** - don't just read
3. **Complete all exercises** in textbook
4. **Test your code** before submission
5. **Participate actively** in discussions
6. **Debug systematically** - learn from errors
7. **Think like a programmer** - focus on problem-solving approach
