## 💬 Discussion Forum Guidelines

### Posting Schedule
- **First Response**: Due by **Sunday**
  - Gives peers time to engage
  - Allows for meaningful discussion
- **Peer Responses**: Throughout the week

### Writing Best Practices
1. **Draft in Word Processor First**
   - Prevents data loss
   - Check formatting before pasting
   - Proofread before posting

2. **Engage Meaningfully**
   - Ask questions
   - Express opinions
   - Provide thoughtful input
   - Build on peer's ideas

3. **Avoid Surface-Level Replies**
   - ❌ "Good job"
   - ❌ "I agree"
   - ✅ Substantive engagement
   - ✅ Real interaction deepens understanding

### Citation Requirements
- **Minimum 3 references** per discussion post
- Use credible academic sources
- Wikipedia: OK for brainstorming, NOT for official citation
- Proper APA format required

## 📚 APA Format Requirements

### Why APA Matters
- Vital professional skill
- Required for all written work
- Demonstrates academic integrity

### Key APA Guidelines

#### Formatting
- ✅ **Consistent double spacing** throughout
- ✅ **No extra space** between paragraphs
- ✅ **Indent all paragraphs** (0.5 inch)
- ✅ **Cite all references** properly

#### In-Text Citations
- Author-date format: (Smith, 2023)
- Page numbers for direct quotes: (Smith, 2023, p. 45)
- Multiple authors: (Smith & Jones, 2023)

#### Reference List
- Alphabetical order
- Hanging indent
- Complete publication information

### APA Resources

**Purdue OWL APA Sample**:
- Comprehensive APA guide
- Sample papers
- Citation examples

**APA Style Blog**:
- Official APA guidance
- Common questions answered
- Updates and clarifications

**Best Practice**: Bookmark these resources and reference frequently
