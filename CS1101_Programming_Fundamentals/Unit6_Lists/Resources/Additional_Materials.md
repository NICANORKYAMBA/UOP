## Key Topics to Review

- `is` vs `==` — identity vs equality
- Aliasing and how to avoid unintended side effects
- In-place methods vs methods that return new objects
- Passing lists to functions — reference semantics
- `split()` / `join()` for string ↔ list conversion
- List comprehensions as concise map/filter patterns
