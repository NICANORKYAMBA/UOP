## Key Concepts Quick Reference

| Concept | Description |
|---|---|
| Mutable | List elements can be changed after creation |
| Equivalent (`==`) | Two lists with same values |
| Identical (`is`) | Two variables pointing to same object |
| Alias | Two variables referencing the same list object |
| Slice | `list[start:end]` — creates a new list copy |
| `append()` | Add element to end |
| `extend()` | Add all elements of another list |
| `sort()` | Sort in place |
| `pop()` | Remove and return element by index |
| `remove()` | Remove first occurrence by value |
