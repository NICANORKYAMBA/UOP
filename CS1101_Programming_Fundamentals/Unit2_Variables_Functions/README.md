## 💡 Study Tips

1. **Practice coding**: Don't just read—type and run code examples
2. **Experiment**: Modify examples to see what happens
3. **Scope matters**: Understand where variables are accessible
4. **Function design**: Break complex problems into smaller functions
5. **Test thoroughly**: Call functions with different inputs
