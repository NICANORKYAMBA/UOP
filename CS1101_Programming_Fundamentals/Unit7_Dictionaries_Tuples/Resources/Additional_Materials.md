## Key Topics to Review

- `dict.items()` vs `dict.keys()` vs `dict.values()`
- `zip()` — stops at shortest sequence
- `enumerate()` — `start` parameter for 1-based indexing
- Tuple immutability — why tuples can be dict keys but lists cannot
- `global` keyword — required to modify, not just read, a global variable
- Dictionary inversion pattern — check-and-append with `if key not in d`
- Memoization with dictionaries — caching recursive results
