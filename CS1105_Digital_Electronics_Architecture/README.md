## Course Description

This course covers digital electronics, logic design, computer arithmetic, memory
systems, programmable logic devices, and computer architecture. Using an online
hardware simulator, we "build" a computer from the ground up and develop an assembler
using concepts learned in class. Topics include number systems, Boolean logic,
combinational and sequential circuits, computer arithmetic, memory hierarchies, and
CPU (Central Processing Unit) design.

There is **no primary textbook**. All required readings and resources are provided in
the weekly Learning Guide (OER-based).

---

## Course Learning Outcomes (CLOs)

- **CLO1**: Explain the principles of Digital Circuits Logic, Boolean Algebra, and number systems.
- **CLO2**: Analyze the principles of logic gate combinations and sequential logic design.
- **CLO3**: Describe the basic principles of memory and the ALU within a computer system.
- **CLO4**: Recognize the relationship between machine language and the functioning of a computer system.
- **CLO5**: Examine basic assembler coding techniques.
- **CLO6**: Explain the concept of computer language hierarchy.

## Tools & Technology

- **Logisim** — online/desktop hardware simulator for building digital circuits.
- **TECS** — The Elements of Computing Systems toolset (Nand2Tetris), used to build a computer and assembler from the ground up.
- **Java v1.5+ JRE (Java Runtime)** — required to run both Logisim and TECS.
- Install instructions are in the **Unit 1 Learning Guide** under "Download and Install Software".
