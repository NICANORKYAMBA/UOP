# CS 1103: Programming 2 — Java

**University of the People**
**Term**: AY2027-T1 (Ends January 31, 2027)
**Credits**: 3
**Prerequisite**: CS 1102 (Programming 1)

---

## Course Description

CS 1103 is a progression from CS 1102, going deeper into Java with advanced concepts:
multithreading, network programming, applets, generic programming, and advanced GUI
programming. Students build robust, efficient software using industry-standard tools
(the **Eclipse IDE** and its debugger), preparing for complex, real-world development.

---

## Course Learning Outcomes (CLOs)

- **CLO1**: Explain programming techniques using Java.
- **CLO2**: Explain advanced Object-Oriented concepts.
- **CLO3**: Use tools such as Eclipse and the Eclipse debugger.

## Textbook & Tools

- **Textbook**: Eck, D. J. (2022). *Introduction to programming using Java* (Version 9, JavaFX ed.). CC 4.0.
- **JDK**: Java (latest suitable version).
- **IDE**: The syllabus references **Eclipse** (CLO3 targets Eclipse + its debugger), but
  this repo uses **IntelliJ IDEA** for all Java work. The concepts transfer directly —
  project setup, running, and the visual debugger (breakpoints, step over/into, watches)
  all exist in IntelliJ. Eclipse-specific instructions map to IntelliJ equivalents.
- Install instructions are in **Unit 1** under "Download and Install Software".
- APA 7th edition for all citations.

## ⚠️ Programming Style Matters

All programs are **graded for style as well as correctness**. Follow the course Java
style guide — see [`Resources/Java_Style_Guide.md`](Resources/Java_Style_Guide.md).
Highlights: Javadoc on every class/non-private method with an `@author` tag, meaningful
names, proper indentation, ≤80-char lines, one statement per line, private member
variables with getters/setters, and named constants via `final static`.
