## Topics to Learn

- Exceptions: `try` / `catch` / `finally`, the exception hierarchy
- Checked vs. unchecked exceptions; `throw` and `throws`
- Creating custom exception classes
- Strings: immutability, common `String` methods
- `StringBuilder` / `StringBuffer`; formatting and parsing

**Reading**: Eck (2022), *Introduction to Programming Using Java* (v9, JavaFX ed.) — exceptions & strings.

## ⚠️ Style Reminder

All code is graded for **style and correctness**. Before submitting, check against
[`../Resources/Java_Style_Guide.md`](../Resources/Java_Style_Guide.md):
- Javadoc on the class with an `@author` tag (your name)
- Javadoc on every non-private method (`@param`, `@return`, `@throws`)
- Meaningful names, ≤80-char lines, one statement per line
- Private member variables; getters/setters as needed
- Reformat before submitting: **Ctrl+Alt+L** in IntelliJ (Ctrl-I in Eclipse)
