## Grading Weights

| Category | Weight |
|----------|--------|
| Discussion Forums (Units 1, 4, 5, 6, 7) | 25% |
| Programming Assignments (Units 1, 2, 3, 6, 7, 8) | 45% |
| Graded Quizzes (Units 3, 6) | 10% |

Programming assignments carry the most weight — and are graded for **style + correctness**.
